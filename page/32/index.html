异常

发表于 2020-01-06 更新于 2026-09-13 分类于 java

异常类

分类：

  1. 错误(Error)。一般指与虚拟机相关的问题，如系统崩溃，虚拟机错误，动态链接失败等，这些错误无法恢复或捕获，将导致应用程序中断
  2. 异常(Exception)。编码错误或外在因素导致。能被系统捕获并进行处理，避免应用程序非正常中断

异常(Exception)：

  1. 运行时异常(RuntimeException)。一般因编码或设计不当导致，可以避免，不要求强制处置，由java运行时系统处理
  2. 非运行时异常。编译时能够检测到，必须捕获或者声明抛出所有非运行时异常，否则编译时无法通过。

异常类常用的方法：

  • public String toString():返回描述当前异常对象信息的字符串
  • public String getMessage():返回描述当前异常对象信息的详细信息
  • public void printStackTrace():打印当前异常对象使用堆栈的轨迹

抛出异常

  • 创建某个Exception的实例
  • 用throw语句抛出，一般放在if分支里
  • 捕获异常并再次抛出新的异常时，应该持有原始异常信息

用户处理异常的方法：

  • try-catch-finally 捕获和处理

    1. 多个catch块时，子类的catch块放前面，父类的catch块放后面(多个catch语句只有一个能被执行)
    2. 执行完catch之后，不会回到异常发生处继续执行，而是执行try-catch结构后面的代码
    3. finally语句无论何种情况都会被执行(除非在之前出现了System.exit()方法)

  • 如果不想捕获和处理异常，可以通过throws语句在方法定义处声明要抛出的异常,交由上一级处理

  • 只要是方法声明的Checked Exception，不在调用层捕获，也必须在更高的调用层捕获。

    所有未捕获的异常，最终也必须在main()方法中捕获，不会出现漏写try的情况。这是由编译器保证的。
    main()方法也是最后捕获Exception的机会。
    如果不想写任何try代码，可以直接把main()方法定义为throws Exception

  • 定义自己的异常类，并用throw语句来抛出

    1. 异常类的定义：继承Exception方法，然后写构造方法，重写toString方法，等等

    2. 使用throw在方法中抛出异常对象：throw语句一般放在if分支里，throw后面紧跟被new出来的异常对象

    3. 含有throw语句的方法，应该在方法头定义中用throws语句声明所有可能抛出的异常（throws后面是异常类）

    4. 在调用该方法时，使用try相关语句，捕获并处理异常

Object类

  1. int hashCode()方法：返回对象的逻辑地址值

  2. Class getClass()方法返回：运行时类的字节码文件(.class文件)对象

    Class 是一个类型，Class类型对应的对象是字节码文件(.class文件)对象

    在一个程序的运行过程中，同一个类所创建的对象所使用的都是同一份字节码文件(字节码文件只会被加载一次)

    同一个类的对象的字节码文件对象是同一个(可以用”==”判断是否是一个类)

    String name=object.getClass().getName()//返回object的运行时类名(getClass—>Class对象—>Class对象的getName)

  3. String toString()方法：返回对象所属类的全名+@+hashcode的16进制表示，(打印一个对象时，其实调的是toString方法)

  4. equals()方法：如果不重写比较的是”==”，是地址值

  5. clone()方法：得到的对象地址值不同，是一个新的对象

    一个对象能否clone，要看该对象的类是否实现了一个标记接口clonable

    如果一个接口内部是空的，那么这个接口叫做”标记接口”

  6. finalize()方法：当对象被判定为垃圾对象时，由JVM自动调用此方法，用以标记垃圾对象，进入回收队列。

    垃圾对象：没有有效引用指向此对象时，为垃圾对象

    垃圾回收：由GC销毁垃圾对象，释放数据存储空间

    自动回收机制：JVM的内存耗尽，一次性回收所有垃圾对象

    手动回收机制：使用System.gc();通知JVM执行垃圾回收

面向对象

发表于 2020-01-04 更新于 2026-09-13 分类于 java

面向对象(OOP):本质是以类的方式组织代码，以对象的方式组织(封装)数据

三大特性：

  1. 封装（高内聚，低耦合；属性私有，set/get）
  2. 继承
  3. 多态

方法

this

  • 可使用this.方法名/属性名，调用同类相关方法和属性
  • 如果没有命名冲突，可以省略this。但是，如果有局部变量和字段重名，那么局部变量优先级更高，就必须加上this

可变参数(String… names)

  • 可变参数必须放在形参列表的最后一个位置
  • String… names**(可以保证无法传入null)**，names本质上是一个数组
  • 实参可以是不固定数目的数，也可以是一个数组

重载

  • 方法名必须相同，方法形参必须有所不同

参数绑定

  • Java本质都是值传递(基本类型复制的是数据本身，引用类型复制的是地址)
  • 类对基本类型是复制数据本身，新开内存。对引用类型是复制指向地址，内存数据本身变化了，类读出数据跟着变化。但字符串修改，是新开内存新指向，已经不能影响类数据。

构造方法

  1. 和类名相同
  2. 没有返回值

作用

  1. new本质在调用构造方法
  2. 初始化对象的值

注意点

  1. 不写构造方法时，编译器会自动生成一个无参的构造
  2. 定义有参构造之后（Java自动生成的无参构造就会消失），如果想使用无参构造，需显式的定义一个无参的构造，（一般重写了有参构造之后，需要自己手动加上无参构造）

多构造方法

  • 一个构造方法可以调用其他构造方法，这样做的目的是便于代码复用。调用其他构造方法的语法是this(…)并给出参数

继承

  • 继承是指子类继承某些父类属性和方法，通过子类或子类对象访问这些属性和方法
  • Java一个类有且仅有一个父类。只有Object特殊，它没有父类。（Object类是所有类的父类）

super

  • 可使用super.方法名/属性名，调用父类中**（必须是非private）**的相关方法和属性
  • 需要注意的是static方法内部不能使用super和this
  • 在java中，任何class构造方法的第一行语句必须是调用父类构造方法。如果没有明确地调用父类的构造方法，编译器会自动帮我们加一句super()（代表调用父类的无参构造）;super和this不能同时调用构造方法
  • 如果父类由于定义有参构造导致没有无参构造时，子类就必须显式调用super(…)并给出参数以便让编译器定位到父类的一个合适的构造方法。此外，子类不会继承任何父类的构造方法。子类默认的构造方法是编译器自动生成的，不是继承的。

向上转型

  • 因为下面继承类的实例也是父类的实例
  • 向上转型后可以访问子类的重写方法(多态的特性)，不能访问非重写的方法(因此向上转型会丢失方法)

向下转型

  • 需要强制转换
  • 向下转型后可以访问子类的方法和子类继承父类的方法

作用域

  1. private字段和方法：不能被继承
  2. protected字段和方法：可以被继承
  3. default字段和方法：同一个包下可以继承，不同包下不能被继承
  4. public字段和方法：都可继承

总结：在包内，除private字段和方法外均可被继承；在包外，除private、default字段和方法均可被继承

  • static：是否能被继承取决于以上几个条件，但是static修饰的方法不能重写(子类中可以存在与父类相同的static方法，但是这不属于重写)，static属性可以读取和修改。
  • final：**是否能被继承取决于以上几个条件，但是final修饰的方法或属性不能重写或修改，只能读取；**如果类被final修饰，这个类不可以被继承

多态

多态产生的条件

  1. 多态是方法的多态，属性没有多态

  2. 有继承关系，且父类的引用指向子类的对象，即 Father f1=new Son();

  3. 方法的重写才是导致多态产生的原因（没有重写就不存在多态）；==>如果不存在方法的重写关系，那么执行哪个方法仅仅取决于左边定义的类中有哪些方法，示例如下：

多态的特性

  1. 运行期才能动态决定调用的子类方法。对某个类型调用某个方法，执行的实际方法可能是某个子类的重写方法。
  2. 可见，多态具有一个非常强大的功能，就是允许添加更多类型的子类实现功能扩展，却不需要修改基于父类的代码。

重写：父类中被子类继承的方法才可被子类重写！

  1. 方法名必须相同

  2. 参数列表必须相同

  3. 修饰符：范围可以扩大但不能缩小:（public>protected>default>private）,父类的private方法不可以被重写

  4. 抛出的异常：范围，可以被缩小，但不能扩大：ClassNotFoundException->Exception(大)

  5. @Override注解帮助在编译时检查是否重写正确(参数，返回类型，名字均需相同)

  6. 父类中不能被重写的方法如下：

    1. static方法，属于类，它不属于实例
    2. final 存放于常量池中
    3. private 方法
    4. 未被继承的方法（参见继承一节作用域）

  7. 静态方法不可以被重写；==>父类和子类中含有相同的（名字相同）静态方法时，可认为他们是两个不同的方法，不存在重写的关系；==>父类与子类静态方法的调用只和左边定义的类有关,示例如下：

    类A是类B的父类，test方法是A，B类中都有的同名静态方法

调用super

  • 在子类的重写方法中，如果要调用父类的被重写的方法，可以通过**super.父类方法**来调用。

instanceof和类型转换

  1. 如果类A和类C存在继承与被继承的关系，编译不会报错（看=左边）
  2. 如果new的对象是C的实例，也即（B是C的子类或者本身）则返回true(看=右边)
  3. 子类转为父类，向上转型，会丢失一部分方法
  4. 父类转为子类，向下转型，需要强制转换。

抽象类 abstract

  • 定义了public abstract方法必须定义abstract类，抽象方法只有方法头，没有方法体
  • 抽象类无法new一个对象，只能靠子类实现它，相当于定义了“规范”
  • 抽象类可以包含普通方法，普通方法不用被重写
  • 子类继承抽象类时，必须重写抽象方法，否则仍为抽象类（仍需用abstract关键字修饰）
  • 抽象类含有构造方法，虽无法new对象时调用，但是可以供子类调用
  • 局限性：类只能单继承，接口可以多实现

接口 interface

普通类：只有具体实现

抽象类：具体实现和规范（抽象方法）都有

接口：只有规范，无法写方法；约束和实现分离：面向接口编程

  • implements关键字可以实现多个接口

  • 一个interface可以继承自另一个interface

  • 在interface中的方法前添加default关键字：实现类不必覆写default方法，只需要在需要覆写的地方去覆写新增方法。非default关键字修饰的则必须要实现。

  • 接口不能被实例化，接口中没有构造方法

  • 修饰：

    接口变量默认都是 public static final,不需修饰，一般不在接口中定义常量。
    接口方法默认都是public abstract,不需修饰。但在实现接口方法的类中，修饰符为public

静态字段和静态方法

  • 静态字段属于所有实例“共享”的字段，实际上是属于class的字段；根本原因是：静态方法/变量在编译时就写入内存(和类同时存在)，非静态变量/方法只有在instance创建时(实例化)才有了意义，这时才可以访问

  • 静态字段在自身类中可直接被访问，在外部类中直接通过类名即可访问，不需创建实例对象

  • 在静态方法中：

    1. 如需访问本类中的非静态方法，必须先创建实例对象；（重点记忆本条就行）
    2. 无法访问this、super；（重点记忆本条就行）
    3. 可以直接访问静态字段和其他静态方法。

  • 在非静态方法（不带static）中：

    可直接调用本类中其他静态或非静态字段(全都能调用)

  • 静态方法常用于工具类(Arrays.sort(),Math.random()等)和辅助方法(程序的入口main)。

  • 匿名代码块：每次创建对象时就执行一次，且在构造方法之前

  • 静态代码块：只在类定义时，仅仅执行一次

包package

  • 包没有父子关系。java.util和java.util.zip是不同的包，两者没有任何继承关系。import mr.jun.Arrays(大写字母为类)表示Arrays是mr.jun包中的一个类，将这个类导入。

  • 在写import的时候，可以使用“*”，表示把这个包下面的 所有class 都导入进来（但不包括子包的class）

  • 如果是简单类名，java编译器按照以下顺序查找

    1. 查找当前package是否存在这个class(自动import当前package的其他class)
    2. 查找import的包是否包含这个class
    3. 查找java.lang包是否包含这个class
      (自动import java.lang.*)=>即导入java.lang包下的所有类(类的命名以大写字母开头)

  • 如果有两个class名称相同，例如，mr.jun.Arrays和java.util.Arrays，那么只能import其中一个，另一个必须写完整类名。

  • import static语法，可导入一个类的静态字段和静态方法

作用域

  • public：对所有类均可见，(即在所有类中均可访问该类的public)

  • private：只有本类可见；如果一个类内部还定义了嵌套类，那么，嵌套类拥有访问private的权限

  • **default：**在同一个包下的所有类中均可访问该类的default(在同一个包下就像public一样)

  • protected：其可见性包含default，同时扩展了一个：包外的子类 对象

    子类与父类不在一个包中时:

    1. 子类对象可以访问protected。(本质：子类对象访问的是自己继承下来的protected)

    2. 子类中的父类对象不能访问父类的protected。但是可通过如下方法访问：

      1. super.method() //protected
      2. 把父类的这个protected用static修饰，那么就可以通过父类的对象或者父类本身直接访问

  • final

    1. 方法前加final不可被子类覆写

    2. 类前加final不可被继承

    3. 定义一个类的变量前加final，初始化后不能被修改

    4. final 存放于方法区中的常量池中

  • 一个.java文件只能包含一个public类，文件名必须和public类的名字相同。但可以包含多个非public类。编译后每个类对应一个class文件

内部类

定义

  1. 编译之后生成独立的字节码文件
  2. 可直接访问外部类的私有成员
  3. 可为外部类提供必要的内部功能组件

成员内部类

  1. 在类的内部定义，与属性和方法同属一个级别

  2. 创建内部类对象时，必须依赖外部类对象

    Outer outer=new Outer();

    Inner inner=outer.new Inner();

  3. 当外部类与内部类存在同名属性时，会优先访问内部类属性

    访问外部类属性时，需要在属性名前面加上Outer.this.前缀

  4. 成员内部类中不能定义静态成员，但是可以定义静态常量

静态内部类

  1. 只有内部类才可使用static修饰类

  2. 不依赖外部类对象，可直接通过类名访问，可声明静态成员（静态内部类相当于外部类）

  3. 只能直接访问外部类的静态成员（访问非静态成员需实例化外部类对象，通过外部类对象访问）

局部内部类

  1. 定义在外部类的方法中，作用域仅限于该方法，局部类前不能加任何访问修饰符
  2. 局部类定义之后只能在外部类当前方法中创建对象并使用
  3. 局部内部类中不能定义静态成员，但是可以定义静态常量
  4. 局部内部类访问外部类当前方法中的局部变量时，因无法保障变量的生命周期与自身相同，变量必须修饰为final(即该变量变为常量，存放于常量池中)

匿名内部类

  1. 没有类名的局部内部类(一切特征都与局部内部类相同)
  2. 必须继承一个父类或者实现一个接口
  3. 定义类，实现类、创建对象的语法合并，只能创建一个该类的对象

java入门

java介于编译型语言和解释型语言之间

java把代码编译成“字节码”，针对不同平台分别开发虚拟机，虚拟机加载字节码并执行。

JDK、JRE、JVM

JDK组成

  • 编译器、调试器等工具
  • JRE(运行Java字节码的虚拟机)
    • JVM+Runtime Library

jdk的bin目录下可执行文件

  • java:就是JVM，执行编译后的字节码
  • javac:Java编译器，把java源码文件(.java)编译为字节码文件(.class)
  • jar:把一组.class文件打包为.jar文件，便于发布
  • javadoc:用于从java源码中自动提取注释并自动生成文档
  • jdb:java调试器

变量及运算

基本类型变量(8大基本类型，其余都是引用类型)

  • 基本数据类型

    整型 byte(1个字节) short(2个字节) int(4个字节) long(8个字节)

    1. 最高位为符号位
    2. 15=0xf=0b1111=017（0开头八进制，0x开头16进制，0b开头二进制）
    3. int不写初始值，默认值是0
    4. long 类型数字后面要加上L
    5. 左移右移运算时，要转换成int类型

    浮点数类型 float(4个字节) 加后缀 double(8个字节)

    1. 浮点数类型0.1不能准确表示，判断相等时需要比较差值是否足够小
    2. 浮点数强制转换成整数类型时，直接丢弃后面的小数部分，需要四舍五入时+0.5再进行强制转换，如果转型后超过了整型能表示的最大范围，将返回整型的最大值。
    3. float类型数字后面要加上F
    4. 最好完全避免使用浮点数进行比较(可使用BigDecimal数学工具类)

    字符类型char(2个字节) 可表示unicode编码(中文)

    布尔类型 boolean(4个字节)

    1. 短路运算
    2. 四个字节存储，运算参考整型变量

    常量 (前面加final修饰符，另外修饰符不分前后顺序)，变量名一般大写

    var关键字

引用类型变量（变量指向内容在内存中存储的地址，相当于C++的指针）

  • 类 (引用类型)

  • 接口 (引用类型)

  • 字符串类型(String不是关键字，是一个类) (引用类型) 使用+进行拼接，可将其它数据类型先自动转型为字符串类型

    不可变特性(字符串内容不可变)
    总结:

    1. Java的字符类型char是基本类型，字符串类型String是引用类型；
    2. 基本类型的变量是“持有”某个数值，引用类型的变量是“指向”某个对象；
    3. 引用类型的变量可以是空值null；
    4. 要区分空值null和空字符串””。

  • 数组(引用类型)

    数组所有元素初始化为：整型为0，浮点型为0.0，布尔型为false
    数组创建后大小不可变
    数组变量.length获得数组大小

变量作用域

  1. 局部变量（定义在方法内部的变量）
    • 必须声明和初始化值
  2. 实例变量（定义在方法外部，类中的变量，没有static关键字）
    • 从属于对象
    • 调用时必须new一个实例才能调用
    • 如果未初始化：基本类型初始化为0，引用类型初始化为null
  3. 类变量（定义在方法外部，类中的变量，static关键字修饰）
    • 从属于类（随类一起出现，一起消失）
    • 前面有static关键字
    • 调用时不需要new一个实例即可进行调用

零碎知识点

  1. 标识符由字母，数字，$，_组成，其中不能以数字开头

  2. Java属于强类型语言（先定义后使用）

  3. 小写字母开头定义的变量是基本类型变量，其余都是引用类型变量（数组也是引用类型变量）。

  4. 变量从低范围到高范围可以自动转换，从高范围到低范围需要进行强制转换

流程控制

  1. 判断引用类型变量是否相等时

    “==”判断地址
    s1 != null && s1.equals(“hello”)判断内容是否相等，同时避免s1为null switch匹配字符串时是比较”内容相等”

  2. for each循环无法指定遍历顺序，也无法获取数组的索引。除了数组外，for each循环能够遍历所有“可迭代”的数据类型，包括List、Map等。

数组操作

数组声明时在栈中出现，创建时才在堆中开辟内存空间

Java对象存储在堆中，数组本身对象

  1. Arrays.toString(ns)//打印数组
  2. Arrays.sort(ns)
    • 整型数组（数组的内容是整数），排序后数组内容发生改变。
    • 字符串数组（数组的内容是字符串的地址），排序后数组内容发生改变。但是字符串在内存中均没有任何变化，ns数组的每个元素指向变化了
  3. 多维数组的每个数组元素长度都不要求相同
  4. 打印多维数组可以使用Arrays.deepToString()
