树状数组的应用【重要】

关于树状数组的几个关键问题：

  1. 使用场景？单点更新，区间求和
  2. 区间范围是什么？下例代码中的区间是[1,50008]，也就是两个函数循环中的上下限
  3. 单点更新如何更新？在区间[1,50008]内index索引位置加上一个数value。更新的操作是加上
  4. 区间求和如何求和？求和函数返回的结果是区间[1,index]的和

  • 树状数组的本质：树状数组维护了==> 一个虚拟数组区间[1,50008]内的前缀和

  • 树状数组可以实现：在虚拟数组区间内某个点更新的情况下，自动的维护了虚拟数组区间[1,50008]内的前缀和，更新以及求和时间复杂度都是O(logn)

  • 虚拟数组的一些解释：（1）虚拟数组长度和树状数组一致，都是[1,50008]；（2）虚拟数组初始值都是0；（3）虚拟数组在程序中不用定义（4）自己心里想象虚拟数组

使用树状数组时，需要搞清楚几个问题

  1. 是不是必须要使用树状数组？存在要维护一个数组区间上前缀和的需求，并且区间内数组的值会更新。使用树状数组的题目，往往存在一个特征，同一个前缀和，比如都是[1,m]区间的前缀和，我求解的时机不同，前缀和的结果不一样
  2. 我要维护的数组是谁，维护的区间是什么，这个数组的下标是什么含义，这个数组的值是什么含义？
  3. 我要在这个虚拟数组的哪个位置进行更新，更新时加上多少？
  4. 每次更新前缀和都会改变==>我们什么时候求解前缀和，每次更新之后都求解吗？求哪个区间的前缀和？

总结

总的来说，把树状数组当作一个常用的数据结构，比如栈，了解他的特性和应用场景，就能够做出对应的题目了。

动态规划模板

发表于 2020-11-27 更新于 2026-09-13 分类于 Top150

动态规划入门

满足的条件

  1. 子问题范围更小，且子问题个数有限
  2. 最优子结构：原问题的目标值，一定是由子问题的目标值转移而来
  3. 无后效性：子问题的目标值求解仅局限于子问题的规模，与由哪个母状态转移而来无关

记忆化搜索

优点是：

记忆化搜索可以实现然而普通递推不能实现的问题（或实现起来非常麻烦的问题）

记忆化搜索通常是用在递推关系不那么明确的情况下，使用记忆化可以避免考虑复杂的DP顺序

缺点是：

带来系统栈占用，导致程序性能下降。

递推

常见于需要优化（重点）的DP

保证求解状态的时候，子问题都已经被计算过

需要考虑如何枚举，才能先计算出规模更小的子问题

通常有这样一个技巧：状态转移方程中，如果是减法，就正序计算；如果是加法，就倒序计算。（优化空间复杂度时除外）

复杂度

无论递推还是递归本质都是遍历整个图

复杂度就是遍历这个图的复杂度

点数：状态数

边数：状态数*转移数

复杂度：状态数*转移数

解题步骤

  1. 定义问题状态:定义问题的状态（也就是递归树中的点），以及目标值
  2. 考虑状态转移:考虑当前状态做出的选择（也就是递归树中的边），得到当前状态转移成的子状态，问题规模得到减小。
  3. 递归或递推解决子问题:解决规模更小的子问题，并通过子问题的结果更新答案。定义最小的子问题的初始值。

经典例题

  • 最长连续上升子序列

    1. 定义状态: dp[i]表示以位 置i结尾的最长连续上升子序列长度
    2. 考虑转移: if a[i]>a[i-1]: dp[i]=dp[i-1]+1 else dp[i]=1

  • 最长上升子序列

    1. 定义状态: dp[i表示以位 置i结尾的最长上升子序列长度
    2. 考虑转移: for each j<i if a[i]>a[j]: dp[i]=dp[j]+1

  • 最长回文子序列

    1. 定义状态: dp[i][j]表示只考 虑序列i~j部分的最长回文子序列长度
    2. 考虑转移: dp[i][j]=max(dp[i+ 1][j],dp[i][j-1]) ；if (a[i]==a[j]) dp[i][j]=max(dp[i][j],dp[i+1][j-1]+2)

  • 最长公共子序列

    1. 定义状态: dp[i][j]表示只考虑第一个序列的前i个，第二个序列的前j个的答案
    2. 考虑转移: dp[i][j]=max(dp[i-1][j],dp[i][j-1]) ；if (a[i]==b[j]) dp[i][j]=max(dp[i][j],dp[i-1][j-1]+1)

总结

  1. 动态规划本质即为递归子问题+备忘录空间换时间

  2. 三步解题法:定义状态（根据经验，熟悉几种dp模型），重点：考虑转移（思路，去想当前状态或问题有哪几种子问题），递归/递推

    1. 状态的定义一般根据经验，熟悉几种dp模型

    2. 转移：从集合的角度去想当前状态有哪几种子问题（分治的思想），考虑当前状态的子问题时要做到不重不漏。

      很重要的划分依据：”最后”

  3. 递归写法为记忆化搜索，递推写法为从小状态枚举到大状态

  4. 复杂度为状态*转移

转移思想1==>枚举k进行划分

先对小区间进行求解，然后再利用小区间的最优解合并求得大区间的最优解。区间dp的思想类似于记忆化搜索->迭代k->后续遍历（包含合并操作）

模板

  1. 定义状态：状态为DP(L,R)表示(L~R)区间的最优解

  2. 考虑转移：转移为枚举区间划分点DP(L,R)=DP(L,K)+DP(K+1,R)+cost(L,R,K)

    k的范围的确定这样想：我需要划分为子问题，因此新划分的区间要比当前的小==>思考一下石子合并问题的k的范围

  3. 递归递推求解子状态：递推为从短的枚举到长的，同时思考区间长度为1的初始化问题==>思考一下石子合并问题的枚举

  4. 复杂度分析：状态O(N^2) 转移O(N)，总复杂度O(N^3)

  5. 结合石子合并例题即可理解透彻

  6. 写代码注意的地方【重要】

    1. 初始化dp数组为最大或者最小
    2. 如何划分区间；K的取值范围(要保证：不能划分之后问题规模没有减小，不能出现和原问题相同的子问题)
    3. 枚举区间时从区间长度为2的地方开始枚举（不一定是2，具体问题具体分析，划分多边形问题从3开始，恐狼先锋从1开始）
    4. 枚举区间之前，先处理枚举起点之前的dp数组的值
    5. 求最大最小值（遍历K之前）之前要先给定一个极小或者极大值
