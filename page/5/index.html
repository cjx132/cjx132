如何手写一个堆?

  1. 插入一个数　　　　　heap[ ++ cnt] = x; up(cnt);
  2. 求集合当中的最小值　heap[1];
  3. 删除最小值　　　　　swap(heap[1],heap[cnt]); cnt -- ; down(1);
  4. 删除任意一个元素　　swap(heap[k],heap[cnt]); cnt -- ; down(k); up(k);
  5. 修改任意一个元素　　heap[k] = x; down(k); up(k);
