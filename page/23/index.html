三数之和

发表于 2020-08-22 更新于 2026-09-13 分类于 Top-100

题目

综述

先排序，后双指针（步步逼近，时间复杂度通常为O(n)，常用于排序数组）

具体思路如下：

  • 固定 3 个指针中最左（最小）数字的指针 k，双指针 i，j 初始设在数组索引 k+1，len-1两端，通过双指针交替向中间移动，记录对于每个固定指针 k 的所有满足 nums[k] + nums[i] + nums[j] == 0 的 i,j 组合：
    1. 当 nums[k] > 0 时直接break跳出：因为 nums[j] >= nums[i] >= nums[k] > 0，即 33个数字都大于 0 ，在此固定指针 k 之后不可能再找到结果了。
    2. 当 k > 0且nums[k] == nums[k - 1]时即跳过此元素nums[k]：因为已经将 nums[k - 1] 的所有组合加入到结果中，本次双指针搜索只会得到重复组合。
    3. i，j 初始设在数组索引 k+1，len-1两端，当i < j时循环计算s = nums[k] + nums[i] + nums[j]，并按照以下规则执行双指针移动：
      • 当s < 0时，i += 1并跳过所有重复的nums[i]；
      • 当s > 0时，j -= 1并跳过所有重复的nums[j]；
      • 当s == 0时，记录组合[k, i, j]至res，执行i += 1和j -= 1并跳过所有重复的nums[i]和nums[j]，防止记录到重复组合。

去重的关键操作：

  1. 排序之后利用单调性才可以使用双指针
  2. 枚举三个树中第一个数时，如果当前枚举的数和前一个数相等时跳过
  3. 枚举后面两个数时，当需要i++或者j–的操作时（说明此时的i和j满足题意或者未满足题意，已经使用过），和他们相等的数字一律跳过
  4. 小技巧：第一个数>0一定不满足条件
